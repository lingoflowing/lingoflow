# LingoFlow v1 Phase3

## 内容

- 5単語データ
- 中国語音声読み上げのみ
- 5単語自動ループ
- イラストは枠のみ
- 背景なし
- フォント・サイズは仮
- BGMなし
- アニメーションなし

## ループ順

1. 朝
2. MRT
3. 雨
4. 夜
5. 茶
6. 朝に戻る

## 再生順

各カードで:

1. 単語の中国語
2. 少し間
3. 例文の中国語
4. 少し余白
5. 次カードへ

## 確認項目

- 5件が順番通り進む
- 茶の次に朝へ戻る
- 停止で即停止する
- 停止後は現在カードを維持する
- 再開で同じカードから始まる
- タブを離れると停止する
- 二重再生しない
- 横スクロールしない
