# LingoFlow ambient v0.12

## 方針

- 1画面
- 1ボタン
- 固定順
- 単語 → 間 → 例文 → 静かな余白 → 次
- タブ離脱・スリープ復帰で勝手に再開しない
- iPhone SE 横スクロールなし
- BGMなし

## v0.12 変更点

- fade を 240ms から 420ms へ変更
- 単語後の間を 1.2秒へ変更
- 例文後の余白を 3.5秒へ変更
- 背景と文字を少し暖かく、柔らかく調整
- 再生ボタンの主張をさらに弱める
